    SECTION 1 — Auth Status (SET-01):
    - Fetches logged-in user via `supabase.auth.getUser()` from the server client
    - Displays user email in a read-only field
    - Shows "Sign out" button (calls `supabase.auth.signOut()` then redirects to /login)
    - This is a Server Component read, Client Component sign-out action

    SECTION 2 — Scanner Token Management (SET-02, TOKEN-01, TOKEN-02, TOKEN-03):
    - Lists existing tokens from `scanner_tokens` table (SELECT via server client)
    - Each token row shows: label, created_at, last_used, revoked status
    - "Generate new token" button:
      - Opens a modal (or inline panel)
      - Prompts for a label (e.g. "zorin-laptop-2026")
      - On submit, calls Server Action `generateScannerToken(label)` from @/lib/actions/tokens
      - Raw token is displayed ONCE in the modal with:
        (a) a copy-to-clipboard button
        (b) the ready-to-run scan command: `SCANNER_TOKEN=<rawToken> SCANNER_API_URL=https://zorinrestore.vercel.app python -m scanner scan`
        (c) a warning banner: "This token will not be shown again."
        (d) a checkbox "I have copied this token" that must be checked before "Done" button activates
      - After dismissal the token is gone — the table row only shows the label and created_at
    - "Revoke" button on each token row:
      - Calls Server Action `revokeToken(tokenId)` from @/lib/actions/tokens
      - Confirmation prompt: "Revoke this token? The scanner will no longer be able to upload."
      - On confirmation, token row shows "Revoked" badge and Revoke button disappears

    SECTION 3 — Machine Name (SET-04, MACH-01):
    - Reads machine label from `machines` table (SELECT via server client, eq user_id)
    - Displays machine label in an inline editable field
    - Edit pencil icon → transforms to text input + Save button
    - On Save, calls Server Action `upsertMachine({ label })` from @/lib/actions/machines
    - Revalidates page after save (calls `revalidatePath('/dashboard/settings')`)
    - If no machine exists yet, shows "Register your machine" form with label input
