**Required spec sections:**

## What Already Exists
- List all imports Cursor can use directly: createClient, Server Actions (with signatures), types
- Include the full ScanItem TypeScript type
- Reference that app/(dashboard)/inventory/InventoryView.tsx is the client component to replace

## Where to Add It
- Replace app/(dashboard)/inventory/InventoryView.tsx
- Props interface: `{ items: ScanItem[], machine: Machine | null, latestRun: ScanRun | null }`
- Nav bar: add simple horizontal nav to app/(dashboard)/layout.tsx (links to /inventory, /review, /secrets, /export, /settings)

## Layout Description
- Top: machine name + last scan date (from machine.label, latestRun.scanned_at)
- Filter bar: category dropdown (all categories from items) + importance dropdown (All/Essential/Useful/Optional) + "Show ignored" toggle (checkbox, default off)
- Item list: grouped by category (one collapsible section per category, open by default), sorted alphabetically within group
- Each item row: tool_name (bold), version (muted), importance badge (colour-coded), confidence indicator
- Clicking a row opens a slide-over drawer (right side, overlays content) with full item detail

## Item Detail Drawer
- Fields to show: tool_name, category, version, install_path, importance (editable dropdown), confidence (read-only badge), general_note (editable textarea, INV-07), restore_note (editable textarea, INV-08), last_seen (from updated_at)
- has_secret_dep checkbox: "Has secret dependency" — calls flagSecretDep() when toggled; link to /secrets page when checked
- "Advanced / Debug Evidence" collapsible section (closed by default, INV-09): shows metadata JSONB as formatted JSON
- Save button: calls updateItemImportance() and/or updateItemNotes() based on changed fields; shows loading state; shows "Saved" confirmation on success

## Behaviour
- State: selectedItemId (null = drawer closed), filters { category: string | null, importance: string | null, showIgnored: boolean }
- Filter logic: items filtered client-side by category (exact match) and importance (exact match), showIgnored controls whether importance='Ignore' items are visible
- When importance filter is set to a value, showIgnored toggle becomes irrelevant (items with importance='Ignore' only appear when showIgnored=true AND no importance filter is active)
- Drawer: closes on Escape key or clicking outside overlay; unsaved changes show confirmation dialog before close
- Empty states: no items → "No scan data yet. Run the scanner to populate your inventory."; no results after filter → "No items match the current filters."

## Visual Guidelines
- Use Tailwind v4 CSS-first (no tailwind.config.js)
- Card pattern: `className="rounded-lg border p-6 space-y-4"`
- Importance badge colours: Essential=green, Useful=blue, Optional=gray, Ignore=red (muted)
- Confidence badge: high=green dot, medium=yellow dot, low=red dot
- Drawer: fixed right-0, top-0, h-full, w-96, bg-white, shadow-xl, z-50
- Nav bar: horizontal list of links, active link underlined/bold, sticky top-0

## Server Actions Called
- updateItemImportance(itemId: string, importance: string): Promise<{ error?: string }>
- updateItemNotes(itemId: string, notes: { general_note?: string; restore_note?: string }): Promise<{ error?: string }>
- flagSecretDep(itemId: string, value: boolean): Promise<{ error?: string }>

## Env Vars / Config
