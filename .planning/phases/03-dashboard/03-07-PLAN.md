## Layout Description
- Page heading: "Export Inventory"
- Subtitle: "Download your machine inventory as a Markdown rebuild reference or JSON backup."
- Single card with two sections:

**Export Options:**
- Checkbox: "Include ignored items" (default: unchecked) — controls ?include_ignored=true query param on both download links
- When checked: both download links append ?include_ignored=true

**Download Links:**
- "Download Markdown (.md)" — anchor tag, href="/api/export/markdown" (+ ?include_ignored=true when checked)
  - Helper text: "Human-readable rebuild reference with categories, notes, and restore instructions"
- "Download JSON (.json)" — anchor tag, href="/api/export/json" (+ ?include_ignored=true when checked)
  - Helper text: "Structured backup for import or automation"

## Behaviour
- State: includeIgnored: boolean (default false)
- Both anchors are standard <a> tags with download attribute: `<a href="..." download>`
- href is computed from state: `href={\`/api/export/markdown\${includeIgnored ? '?include_ignored=true' : ''}\`}`
- No loading states needed — browser handles the file download natively
- No JavaScript fetch calls — the anchor href triggers the download directly

## Visual Guidelines
- Card: `className="rounded-lg border p-6 space-y-4"`
- Download link buttons: styled as links with an icon (optional), not <button> elements
- Checkbox row: `className="flex items-center gap-2"` with label "Include ignored items"
- Helper text: `className="text-sm text-gray-500"`

## Server Actions Called
None — export is driven by anchor href links, not Server Actions.
