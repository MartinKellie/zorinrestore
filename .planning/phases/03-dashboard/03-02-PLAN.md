    - updateItemNotes("item-id", { general_note: "..." }) → {} when user owns item
    - updateItemNotes("item-id", { restore_note: "..." }) → {} when user owns item
    - updateItemNotes("item-id", {}) → {} (no-op is valid — caller controls which fields to patch)
    - updateItemNotes("item-id", { general_note: "..." }) when unauthenticated → { error: "Unauthorized" }

    RED: Update tests/inventory.test.ts stubs to contain real expectations (not just import checks).
    Tests will fail because lib/actions/inventory.ts does not exist yet.

    GREEN: Create lib/actions/inventory.ts:
    - "use server" directive at top
    - ImportanceSchema = z.enum(["Essential", "Useful", "Optional", "Ignore"])
    - NotesSchema = z.object({ general_note: z.string().optional(), restore_note: z.string().optional() })
    - updateItemImportance(itemId: string, importance: string): Promise<{ error?: string }>
      1. Validate with ImportanceSchema.safeParse
      2. getUser() → return { error: "Unauthorized" } if null
      3. SELECT scan_items by id via createClient() → return { error: "Item not found" } if null
      4. adminSupabase UPDATE scan_items SET importance, updated_at WHERE id
      5. Return {} or { error: message }
    - updateItemNotes(itemId: string, notes: { general_note?: string; restore_note?: string }): Promise<{ error?: string }>
      1. Validate with NotesSchema.safeParse
      2. getUser() → return { error: "Unauthorized" } if null
      3. SELECT scan_items by id via createClient() → return { error: "Item not found" } if null
      4. Build update payload from only the provided fields (spread only defined keys)
      5. adminSupabase UPDATE scan_items SET {fields}, updated_at WHERE id
      6. Return {} or { error: message }

    Use z.record(z.string(), z.unknown()) pattern if needed (Zod v4 requirement).
    DO NOT use getSession() — always getUser().
    DO NOT expose adminSupabase to any client path.
  </implementation>
