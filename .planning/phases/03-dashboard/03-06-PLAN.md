- Replace app/(dashboard)/secrets/SecretsView.tsx
- Props: `{ reminders: SecretReminder[], envItems: ScanItem[], flaggedItems: ScanItem[] }`

## Layout Description
- Page heading: "Secrets Checklist"
- Subtitle: "Track which secrets need to be recreated during a machine rebuild. Values are never stored."
- Three sections:

**Section 1 — Detected .env Variables (SEC-01)**
  - Source: envItems (scan_items where category='env_files')
  - For each env item: show tool_name (the file path), then list metadata.variable_names array (the variable names detected)
  - Read-only display — these come from the scanner
  - Empty state: "No .env files detected. Run the scanner to populate."

**Section 2 — Manual Reminders (SEC-01, SEC-02)**
  - List existing reminders: name (bold) + note (muted) + created date + delete button
  - Add reminder form: name input (required, placeholder "e.g. GitHub personal access token") + optional note input + "Add Reminder" button
  - On submit: call addSecretReminder(name, note), on success optimistically add to reminders list, clear form
  - On delete: call deleteSecretReminder(id), optimistically remove from list
  - Values are names/labels only — add helper text: "Add the name of the secret, not its value"

**Section 3 — Inventory Items with Secret Dependencies (SEC-03, SEC-04)**
  - Source: flaggedItems (scan_items where has_secret_dep=true)
  - List: tool_name + category + link to /inventory (scroll to item — use #item-{id} anchor)
  - Empty state: "No inventory items are flagged as having secret dependencies yet. Flag items from the inventory view."
  - Note: flagging is done from the inventory item detail drawer (INVENTORY_UI_SPEC.md), not from this page

## Behaviour
- State: reminders list (local state from props), form state { name: string, note: string }, submitting boolean, deletingId (string | null)
- Add form: validate name non-empty before calling Server Action; show inline error if Server Action returns error
- Delete: set deletingId=reminder.id, call deleteSecretReminder, on success remove from list, clear deletingId
- Both add/delete show loading state on their respective buttons

## Visual Guidelines
- Each section: `className="rounded-lg border p-6 space-y-4"` card
- Variable name tags: `className="inline-block bg-gray-100 text-gray-800 text-xs px-2 py-1 rounded font-mono"`
- Form input: standard text input with label above
- Delete button: small, red text, no background (destructive but not prominent)

## Server Actions Called
- addSecretReminder(name: string, note?: string): Promise<{ error?: string }>
- deleteSecretReminder(reminderId: string): Promise<{ error?: string }>
