  <name>Export API Routes</name>
  <files>app/api/export/markdown/route.ts, app/api/export/json/route.ts, tests/export-route.test.ts</files>
  <behavior>
    - GET /api/export/markdown (unauthenticated) → 401 JSON { error: "Unauthorized" }
    - GET /api/export/json (unauthenticated) → 401 JSON { error: "Unauthorized" }
    - GET /api/export/markdown (authenticated, no machine) → 200 empty inventory markdown
    - GET /api/export/markdown (authenticated, has items) → 200 text/markdown attachment
    - GET /api/export/markdown?include_ignored=true → includes ignored items in ## Ignored Items section
    - GET /api/export/json (authenticated) → 200 application/json attachment with items array
    - GET /api/export/json?include_ignored=true → JSON has "ignored" key with separate array
    - Default (no ?include_ignored) → items with importance="Ignore" are excluded
  </behavior>
  <implementation>
    RED: Update tests/export-route.test.ts stubs (from plan 03-01) to include full expectations.
    Tests fail because route files don't exist.

    Create app/api/export/markdown/route.ts:
    - export async function GET(request: NextRequest)
    - Auth check: createClient().auth.getUser() → 401 if no user
    - include_ignored = request.nextUrl.searchParams.get("include_ignored") === "true"
    - Resolve machine (single, by user_id) — if no machine, return empty inventory markdown
    - Resolve latestRun (most recent scan_run for machine) — if no run, return empty inventory
    - Fetch items: if !include_ignored add .neq("importance", "Ignore") filter
    - Group items by category using Array.prototype.reduce (NOT Object.groupBy — Node compat)
    - Build markdown string: header block + one ## section per category (sorted alphabetically)
    - If include_ignored=true, collect ignored items separately and append ## Ignored Items section
    - Return new Response(markdown, { headers: { "Content-Type": "text/markdown; charset=utf-8", "Content-Disposition": 'attachment; filename="machine-inventory.md"' } })

    Create app/api/export/json/route.ts:
    - Same auth + machine + latestRun pattern
    - Build JSON: { machine: {...}, generated_at: new Date().toISOString(), items: [...] }
    - If include_ignored=true: split items into active + ignored, add "ignored" key to JSON
    - Return new Response(JSON.stringify(data, null, 2), { headers: { "Content-Type": "application/json; charset=utf-8", "Content-Disposition": 'attachment; filename="machine-inventory.json"' } })

    Ensure directory app/api/export/markdown/ and app/api/export/json/ are created.
    DO NOT use NextResponse for the file download responses — use bare new Response() for correct streaming behavior.
    DO use NextResponse.json() only for the 401 error response.
  </implementation>
